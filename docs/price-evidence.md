# 采购价格来源截图

## 当前覆盖

京东商品搜索结果（shopping_comparison、product_search）显示每个商品的来源截图缩略图，点击打开原生对话框；Escape、关闭按钮和遮罩都能关闭，并把键盘焦点还给缩略图。手机与桌面共用同一证据数据。

历史记录没有截图不会回填当前价格冒充旧证据，显示“未留存价格来源截图”。图片被删除/无法加载时显示缺失说明；不使用商品宣传图片、占位图或模型绘图替代。

**三家商超通道目前未核验。** 检查发现旧实现将京东不同商品分配成沃尔玛、比优特、华润万家的价格，甚至按比例估价。HTTP 与聊天都已停止这条路径，旧缓存也不再作为实时比价展示。不会为其附上京东截图充当三家门店的证据，也不静默替换平台。旧数据文件保留审计和模拟订单兼容，未删除用户历史。

## 采集链

1. 服务端按白名单构建京东搜索 URL，使用 ego-browser 读取搜索结果的真实 SKU、标题、价格、条件、店铺。
2. 按精确 data-sku 定位商品卡片，滚动并截取**该卡片**，不截账户头部、用户名、配送地址、聊天或整个桌面。
3. 截图前后重新读取同一 SKU。标题、价格、价格条件、店铺或优惠文字变化时，放弃该截图，不替换成其他 SKU。
4. 商品卡片过大、截图超时、存盘失败、PNG 无效时，返回商品结果但无截图，UI 如实提示。截图异常后不继续盲拍其他卡片。
5. 成功的 PNG 和 JSON 元数据以服务端 UUID 不可覆盖地保存；元数据包括绑定商品、页面来源、时间（UTC ISO）、条件和图片 SHA-256。界面显示北京时间。
6. evidence 字段随 BrowserTaskRun 商品快照保存在当前应用原有的本地持久化记录中。重复查看旧记录仅读取已保存图片，不重新搜索，不调用多模态模型。

截图是“搜索页商品卡片裁图”，不是商品详情页实付核价，不证明官方授权、库存、最终运费或无条件结算价。缩略图和大图使用同一原始 PNG，CSS 缩小，不创建 AI 图片。标题/价格/条件不匹配的图片元数据无法作为此商品的来源显示。

## 存储与访问

- 默认 `data/price-evidence/`，已加入 Git 忽略；可由服务端 `PRICE_EVIDENCE_DIR` 指定私有持久化路径。
- 不放 public/ 或 dist/。目录权限 700，PNG/JSON 权限 600。
- `GET /api/price-evidence/<uuid>.png` 与搜索接口使用相同认证检查；UUID/扩展名白名单防止任意路径读取。返回前校验哈希及 PNG。
- 图片 `Cache-Control: private`，不允许跨站嵌入。生产环境必须将此路径也放在**已认证的同源反向代理**后，不能仅代理 `/api/ego-browser/*`。
- 浏览器 img 不会添加自定义 token header；生产代理应先用同源登录态认证，再向桥接服务注入 `x-ego-bridge-token`（与现有搜索接口相同）。不要把该 token 放进图片 URL 或前端代码。
- 文件默认保留直到管理员清理；删除后旧记录会提示截图缺失。备份时同时备份私有 PNG 和元数据，不公开共享包含个人会员价格的截图。

## 验证

`tests/price-evidence.test.js` 使用隔离临时目录，覆盖截图前后 SKU/价格绑定、PNG 与哈希、不可用截图、CLI 回传持久化、路径/权限/跨站访问及 UI 触发器。模拟 PNG 只存在于单元测试临时存储，绝不当生产商品截图。

本轮另做一次正式京东“茉莉花茶”查询，返回 10 条商品及 10 张商品卡片来源裁图；人工打开图片核对标题、PLUS 价格与店铺，并在真实浏览器检查缩略图放大、Escape、焦点恢复及 1440/768/390 三种宽度。
